# 会話ポートレートの差し替え（任意）

ここに**所定の名前のPNG画像**を置くと、ゲームがそれを優先して会話ウィンドウに表示します。
画像が無い場合は、ゲームが内蔵のドット絵ポートレート（コード生成）を使います。
ファイルを置くだけで反映されます（コードの変更・設定は不要）。

## ファイル名

| 話者 | ファイル名（基本） | 備考 |
|------|-------------------|------|
| ルカ（主人公） | `luca.png` | |
| ノア（ナビAI） | `noa.png` | |
| コロニーの声 | `voice_man.png` | ステージ1の通信 |
| 少女の声 | `voice_girl.png` | ステージ2の通信 |
| 研究員の声 | `voice_sci.png` | ステージ3の通信 |
| 自動音声 | `voice_auto.png` | ステージ4の通信 |
| 機械生命体 | `machine.png` | |
| マザー機 | `mother.png` | |

## 差分（任意）

基本画像（例: `luca.png`）があるときだけ、次の差分を探します。無ければ基本画像を使います。

- 話している間の口パク: `luca_talk.png`
- 表情差分: `luca_worry.png`（不安）/ `luca_sad.png`（悲しみ）/ `luca_smile.png`（笑顔）/ `luca_determined.png`（決意）/ `luca_surprise.png`（驚き）
- 表情＋口パク: `luca_sad_talk.png` のように `<名前>_<表情>_talk.png`

探す順序：`<名前>_<表情>_talk` → `<名前>_<表情>` → `<名前>_talk` → `<名前>`

## 画像の仕様

- 形式：PNG（透過可）。
- 推奨サイズ：**縦長の半身像 160×192 px 以上**（表示枠は 80×96 の論理ピクセル。大きい画像は縮小して表示します）。
- 縦横比は保たれ、枠の下端・中央に合わせて収まります。背景は透過にするか、暗い背景を含めてください。
- 高解像度のイラストは滑らかに縮小、小さなドット絵（120px 以下）はドットを保ったまま表示します。
- 画像は `file://` でも読み込めます（`<img>` と同じ扱い）。

## 注意

- 他人の著作物・既存ゲームの画像など、権利のない画像は使わないでください。
- ファイル名は小文字・半角で、拡張子は `.png`。名前が違うと読み込まれません。
